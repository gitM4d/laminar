# Laminar

Version: Draft 1

---

# Executive Summary

Laminar is an intent-centric capital allocation protocol built for DeFi users who want optimized yield generation without continuously monitoring protocols, rates, liquidity conditions, and risk exposure.

Unlike traditional vault protocols, Laminar does not pool user funds into shared vaults.

Instead, every user maintains ownership of assets through an individual smart account while Laminar provides portfolio construction, monitoring, risk analysis, and automated rebalancing within explicitly approved constraints.

The protocol acts as an orchestration layer rather than a custody layer.

---

# Problem Statement

DeFi users face several challenges:

- Yield opportunities constantly change.
- Capital is fragmented across protocols.
- Risk profiles vary between users.
- Monitoring requires significant time and expertise.
- Manual rebalancing is inefficient.
- Existing vault products force users into predefined strategies.

Most yield products optimize capital globally.

Very few optimize capital individually.

Laminar is designed to solve this problem.

---

# Vision

Create the first truly intent-centric capital allocation layer for DeFi.

Users should define objectives.

Laminar should determine execution.

The protocol should continuously align capital allocation with user intent while respecting risk constraints and operational boundaries.

---

# Core Philosophy

Traditional DeFi asks:

"Where should I deposit my funds?"

Laminar asks:

"What outcome are you trying to achieve?"

The user defines:

- risk tolerance
- liquidity preferences
- return preferences

Laminar constructs and maintains the portfolio.

---

# What Laminar Is

Laminar is:

- a portfolio orchestration protocol
- a capital allocation engine
- a risk-aware automation layer
- an intent-based portfolio construction system
- a multi-protocol yield allocator

---

# What Laminar Is Not

Laminar is not:

- a shared vault protocol
- a custody provider
- a leverage platform
- a trading platform
- a speculative yield farm

---

# Key Differentiators

## User-Intent-Centric

Portfolio construction begins with user objectives rather than protocol selection.

---

## Personalized Portfolios

Each user may have different:

- risk targets
- liquidity requirements
- return preferences

Laminar supports individualized portfolio construction.

---

## Explainable Routing

Users can inspect:

- selected protocols
- allocation weights
- risk assumptions
- rebalance rationale

Automation is transparent.

---

## Controlled Automation

Laminar operates only within explicitly approved constraints.

Users define boundaries.

Laminar executes inside those boundaries.

---

## Non-Custodial Architecture

Assets remain in user-controlled smart accounts.

Laminar coordinates capital allocation but does not custody user funds.
